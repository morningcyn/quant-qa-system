## 一、项目概况

把重型中台砍掉，做成**本地单机轻量质检工具**：主管导入聊天记录（粘贴 / TXT / CSV / JSON），大模型按 D端(55分)+S端(45分) 规则自动打分，生成质检报告（总分、59分黄灯熔断、双雷达图、失分归因、原话 vs AI黄金改写、改进建议），并按员工沉淀历史档案（30天趋势、Top3薄弱项）。API Key 由使用者在本机「设置 → 我的模型」配置，绝不烧开发者 token。

**已确认技术决策**：
- 形态：pywebview 桌面窗口（纯 Python：FastAPI 后端 + pywebview 壳 + 手写静态前端，无 Node 构建链）
- 默认模型：DeepSeek（OpenAI 兼容），设置页支持 Anthropic（Claude）双协议
- 权重按打分机制图：D端55（D1情绪转化10/D2画像匹配15/D3诉求穿透15/D4预期超越15）+ S端45（S1情绪维稳20=共情4+定制5+直接4+无冲突5+宣泄引导2；S2问题闭环15；S3专业供给10）；总分<59 黄灯熔断；权重可配置（standard/newbie/vip 三模板）

## 六、关键设计说明（防呆三层 + 熔断重算）

1. **输入侧**：parser 硬校验（角色无法识别 → 400 不进模型）
2. **提示侧**：规则书动态注入 + 轮次编号对齐 + few-shot + 防呆红线
3. **输出侧**：Pydantic 全量校验 + json_guard 提取/修复/字段级重试 3 次 + L2 降温/L3 拆分降级
4. **熔断与总分由后端按模板重算**，不信任模型算术（防模型为避黄灯虚高打分）
5. **模板快照**：每次质检存当时模板满分，改权重不影响历史报告与 Top3
6. **密钥安全**：Windows DPAPI 加密落库（绑定本机用户+机器）、接口掩码、日志脱敏、绝不外传
